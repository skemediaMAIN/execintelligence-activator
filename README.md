# ExecIntelligence Activator

A thin, open-source installer for **ExecIntelligence**. It holds **no proprietary code**.

Install this, enter your licence key, and it downloads your own private ExecIntelligence build
from the licence-gated backend and installs it into your vault. The product itself never travels
through a public channel; only this bootstrap does.

Works on iPad and iPhone as well as desktop.

## Use

1. Install the Activator.
2. Command palette, "Activate ExecIntelligence (enter licence and install)".
3. Paste your licence key.

Your build downloads and enables. If you are upgrading from an installation made before
September 2026, your licence and settings are carried across automatically and the old
installation folder is retired for you.

## Why it exists

The plugin is licensed per customer and each build is watermarked, so it cannot be distributed as
a single shared download. This shim gives the one-click install experience while the real build
stays private and per-customer.
